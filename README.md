# 링파일 · ringfile

YouTube 공개 영상 링크를 MP3 또는 MP4로 저장하는 데스크톱 도구입니다.

현재 공개 베타 전 검증 중입니다. 설치 파일은 검증이 완료된 뒤 Releases에 공개합니다.

- 웹사이트: https://ringfile.xlxor.chatgpt.site/
- Mac: Apple Silicon · macOS 13.5 이상
- Windows: x64 대상
- 설치·변환 도구 포함, 기본 MP3 320kbps와 표지·곡 정보 지원

공개 저장소의 무료 표준 Windows/macOS 실행 환경만 사용합니다. 유료 실행 환경·과금되는 Actions 아티팩트 저장소·결제·광고 SDK는 추가하지 않습니다. CI는 수동 실행이며 설치 파일을 자동 공개하지 않습니다.

실제 운영체제에서 생성한 검사 미디어로 확인한 결과와 YouTube 실다운로드 결과는 구분합니다.
